## 제품 목적 정리

사용자 설명에 따라 제품 목적을 공공 프로젝트의 각종 법령·규칙·가이드라인 충족 안내로 정리했다. 개인정보 로깅은 첫 Vertical Slice로 명시했다.
소개·온보딩·브로슈어를 같은 목적에 맞추고, 적용 영역 확장 후보와 현재 v0.9.0 구현·검증을 구분했다.
본 프로젝트의 INTENT.md·제품 방향·PRD·아키텍처·ADR-0012와 연결한다. 실제 새 규정 검사 기능을 구현했다는 주장은 하지 않는다.
1440px·390px에서 세 페이지 가로 넘침이 없고, 수정 PDF가 A4 2쪽이며 각 페이지에 글자 잘림이 없음을 확인했다.
검사 엔진과 시험 코드는 변경하지 않았으므로 기존 320개 회귀 결과를 다른 규정 영역의 결과로 확대하지 않는다.

## 라이선스 적용

본 프로젝트 Apache-2.0, 별도 가이드 CC BY 4.0을 사용자 지시에 따라 적용했다.
가이드 LICENSE는 CC 공식 법적 원문의 사본이며 웹 다운로드와 같은 바이트다. ATTRIBUTION.md와 license.html에 제공자·출처·변경 표시 예·별도 라이선스 범위를 적었다.
라이선스 페이지를 포함한 한국어 4쪽, 로컬 경로·앵커 56개, PDF SHA-256이 정적 검사를 통과했다.
PDF는 A4 2쪽이며 양쪽 페이지의 CC BY 4.0 표시·클릭 링크와 한글 배치를 검토했다.
소스 기준 태그는 기존 v0.9.0을 보존한 v0.9.0-apache2다. 본 프로젝트 wheel의 SPDX 라이선스와 Apache LICENSE·NOTICE·기존 MIT 원문 포함을 확인했다.
검사 엔진과 기존 회귀 시험의 소스는 변경하지 않았다.

## 파일럿·무상 사용·참여 안내 (2026-10-29)

첫 화면·온보딩·라이선스·브로슈어에 파일럿 단계를 명시했다. 본 프로젝트 코드의 Apache-2.0 무상 사용·상업적 이용·재배포 조건과 별도 가이드의 CC BY 4.0을 구분했다. 실제 기관 파일럿 완료를 뜻하지 않음을 밝혔다.

피드백·기여 웹 페이지와 두 저장소의 CONTRIBUTING.md, 파일럿 피드백·버그·개선 제안 이슈 양식, 접수 경로 설정, PR 템플릿을 추가했다.

- 정적 검사: `python3 scripts/check_site.py`, 한국어 5쪽·로컬 경로/앵커 74개·PDF SHA-256 통과.
- 이슈 양식: Ruby YAML 파서로 8개 파일의 구문, 필수 메타데이터, 입력 ID 중복, 입력 유형, 접수 링크를 확인했다.
- Chrome: 1440px·390px·320px에서 5개 페이지 가로 넘침 없음. 온보딩 체크리스트의 1/8 진행 표시 확인.
- PDF: `PLAYWRIGHT_CHANNEL=chrome node scripts/export_pdf.mjs`로 재생성. `pdfinfo`로 A4 2쪽 확인 후 PNG로 한글·배치·페이지 번호 검토.
- 검사 엔진·시험·정책은 변경하지 않았다. 이번 확인은 문서·양식·안내 사이트에 한정한다.

## 비개발자 안내 개선 (2026-10-29)

첫 화면의 주요 경로를 설치 없는 쉬운 안내(`start.html`)로 연결했다. 민원 처리 사례, 현재 가능한 범위, 역할별 다음 단계, 용어 풀이와 자주 묻는 질문을 추가했다. 설치·실행 안내는 개발 담당자용으로 표시했다. 의견 페이지에는 GitHub 계정·공개 게시 안내와 작성 순서, 짧은 의견 예시를 추가했다. 소개 자료와 PDF도 쉬운 표현으로 갱신했다.

- `python3 scripts/check_site.py`: 한국어 6쪽, 내부 경로·앵커 106개, PDF 체크섬 및 공개 파일 경계 통과.
- 개발 담당자용 안내의 기존 코드 예시·식별자 23개가 동일함을 확인했다.
- Chrome에서 1440px·390px·320px로 6개 페이지의 가로 넘침이 없음을 확인했다. 기존 준비 체크리스트도 동작했다.
- 첫 화면 → 쉬운 안내 → 역할별 다음 단계 → 의견 안내 → 피드백 양식 링크 경로를 확인했다. 의견은 실제 제출하지 않았다.
- PDF 재생성 후 A4 2쪽을 확인하고 페이지 이미지로 한글·줄바꿈·페이지 번호를 검토했다.
- 비개발자 대상 사용성 인터뷰는 수행하지 않았다. 위 결과는 문구·연결 경로·화면 표시 검증이다.
