다양한 공공 프로젝트에서 비개발자가 AI와 함께 업무 도구를 안전하게 만들도록 돕는 것이 목표입니다. 원하는 일을 설명하고, 만든 결과를 시험·수정하며, 필요한 검토와 승인을 받는 과정에 보안 점검을 연결합니다.

프로젝트가 지향하는 업무 흐름

  1. 1우리 업무에 필요한 기준 확인기준
  2. 2해야 할 일과 담당자 정리작업
  3. 3문제를 점검하고 수정 결과 확인점검
  4. 4검토한 사람과 확인 자료 기록기록

‘하네스’는 여러 개발 도구와 점검 절차를 연결해 함께 작동하게 하는 장치입니다. 현재는 민원 내용이 불필요한 기록에 남는 문제를 첫 사례로 확인했습니다.

의견만 남겨도 참여입니다개발 경험 없이도 참여 가능

현재는 시험·개선 단계실제 업무 도입은 별도 검토 필요

개발하는 순간부터,
보안 기준이 작동하도록.

개발자는 수정할 지점을, 보안 담당자는 판단할 근거를, 프로젝트 책임자는 남은 작업을 알아야 합니다. GovCode Harness는 각자의 업무를 하나의 개발 흐름으로 연결하는 것을 지향합니다.

개발자에게는 다음 행동을

점검에서 발견한 문제를 고치고 다시 확인하도록 돕습니다. 첫 사례에서는 민원 원문을 불필요하게 기록하는 코드를 찾아, 수정한 코드가 검사를 통과하는지 확인했습니다.

검토자에게는 판단 근거를

어떤 기준으로 점검했고 누가 검토했는지 확인합니다. 첫 사례에서는 작성자와 승인자를 나누고, 검사 결과의 출처와 변경 여부를 확인할 수 있는 기록을 남겼습니다.

책임자에게는 진행 상황을

점검과 수정이 어떻게 진행됐는지 관리 화면에서 확인합니다. 프로젝트 전체에서 끝난 일, 검토 중인 일, 아직 확인하지 못한 일을 한눈에 보는 기능은 앞으로 확장할 계획입니다.

개인정보·보안 / 접근성

보호 요구와 이용 환경별 점검을 작업·수정·검토 근거에 연결하는 방향입니다.

개발 품질 / 표준·상호운용성

필수 시험과 프로젝트별 개발·인터페이스 기준을 확인하도록 확장합니다.

사업 산출물 / 운영·보존

단계별 문서·검수·운영·보존 요구와 제출 근거를 안내하도록 확장합니다.

특정 업무에 한정하지 않습니다. 민원 로깅은 점검·수정 흐름을 확인한 첫 기술 사례입니다. 이번 프리뷰는 여러 공공 프로젝트에 적용할 사업 정보와 규정 묶음, 문서 작성 기반을 확장했습니다. 이 사례를 쉬운 설명으로 읽어 보세요.

개발과 검토가
같은 근거로 이어집니다.

한국어 관리 화면에서 점검 기준과 결과, 수정 과정을 확인할 수 있습니다. 담당 업무에 따라 볼 수 있는 자료와 승인할 수 있는 일이 달라집니다.

  • 기관·프로젝트·담당 업무에 따라 자료 열람 권한 구분
  • 시험용 계정으로 작성·승인·운영·검토 역할 확인
  • 확인 자료의 변경·삭제 제한과 사본 보관·복구

화면은 가상 자료와 시험용 계정으로 만든 예시입니다. 실제 기관의 직원 계정 연결은 별도 작업이 필요합니다.

파일럿을 함께 경험하고,
다음 개발 흐름을 만들어 주세요.

프로젝트 코드는 Apache-2.0 조건에 따라 개인·기관·기업이 라이선스 비용이나 로열티 없이 사용·수정·재배포할 수 있습니다. 상업적 이용도 가능합니다.

현재는 가상 자료로 작동 과정을 확인하는 프리뷰입니다. 비개발자가 직접 만들고 싶은 업무 도구와 필요한 점검을 알려 주세요. 자연어 요구부터 제작·실행·공유까지 이어지는 전체 경험과 실제 기관 시험 운영은 아직 완성되지 않았습니다.

재배포 시 라이선스·저작권·NOTICE·수정 사실 표시 등 조건을 준수해야 합니다. 무보증 조건이 적용되며 설치·인프라·운영 비용은 사용 환경에 따라 발생할 수 있습니다. 가이드·브로슈어는 CC BY 4.0입니다. 라이선스 안내

지금 실행할 수 있는 것

시험용 프로그램의 문제 발견과 수정 후 재점검, 담당자 승인, 확인 자료의 보관과 복구를 개발 담당자의 컴퓨터에서 시험할 수 있습니다.

도입 전에 확정할 것

우리 기관에 적용할 기준, 참여할 담당자, 사용할 자료와 보관 방법, 시험 범위를 개발·보안 담당자와 함께 정해야 합니다.

지원 경계 현재는 Python이라는 개발 언어의 일부 코드만 점검하며, 전체 시험은 macOS에서 확인했습니다. AI는 미리 준비한 응답으로 동작을 시험했습니다. 실제 AI의 답변 품질은 아직 확인하지 않았습니다.
