공공 프로젝트 규정을
실행 가능한
업무로 연결합니다.

적용되는 법령·규칙·가이드라인을 필요한 작업으로 옮깁니다. 자동화할 수 있는 검사와 수정 지원, 담당자의 검토·승인·증적을 연결해 요구 충족을 안내하는 것이 제품의 목표입니다.

  2. 2규정별 수행 작업·산출물 안내작업
  3. 3자동 검사·수정 지원과 담당자 검토충족
  4. 4승인·예외·증적과 변경 영향 연결추적

자동화 가능한 작업은 검사·수정으로, 책임 있는 판단은 담당자 검토로 연결합니다. 현재 첫 사례에서 공통 정책·증적 기반을 검증했습니다.

첫 사례 320개 회귀 시험 통과실패 0 · 건너뜀 0, 로컬 참조 기준

기관 내부 실행 지향공개 사이트는 안내 자료만 제공

어떤 요구를 충족해야 하는지,
다음에 무엇을 해야 하는지.

발주기관과 수행사는 프로젝트 조건에 맞는 기준을 적용하고, 설계·개발·시험·검수·운영의 작업과 근거를 연결해야 합니다. 이 전체 과정을 안내하는 제품으로 확장합니다.

적용 요구를 작업으로

출처·버전·적용 조건을 확인한 요구를 담당자·수행 작업·산출물·검사에 연결하는 것이 목표입니다. 범용 프로젝트 프로필과 규정 팩은 후속 설계 범위입니다.

충족 작업의 자동화

자동 검사·수정 지원·재검사로 요구 충족을 돕습니다. 현재는 첫 로깅 사례와 공통 정책·승인·게이트 기반을 구현했고, 다른 분야의 검사와 산출물 지원은 확장할 계획입니다.

완료까지 근거 추적

충족·미충족·검토 대기·미검증을 근거와 함께 안내하는 것이 목표입니다. 현재는 첫 사례의 서명 증적·이력·보관·복구 기반을 검증했습니다.

공공 프로젝트 수행 전반을
규정 팩으로 확장합니다.

다음은 확장 후보입니다. 모든 프로젝트에 적용되는 의무 목록이나 현재 구현한 검사 목록이 아닙니다.

개인정보·보안 / 접근성

보호 요구와 이용 환경별 점검을 작업·수정·검토 근거에 연결하는 방향입니다.

개발 품질 / 표준·상호운용성

필수 시험과 프로젝트별 개발·인터페이스 기준을 확인하도록 확장합니다.

사업 산출물 / 운영·보존

단계별 문서·검수·운영·보존 요구와 제출 근거를 안내하도록 확장합니다.

첫 사례가 보여 주는 공통 흐름 민원 API 개인정보 로깅 위험을 탐지해 deny → 수정 → 새 commit 재검사 → allow → 증적으로 연결했습니다. 이 결과가 다른 규정 분야의 자동 충족을 증명하지는 않습니다.

실행·정책·증적을
같은 화면에서 확인하세요.

한국어 관리 화면에서 역할별로 정책과 실행을 살펴보고, 수정·재검사·예외 이력을 따라갈 수 있습니다.

  • 기관·프로젝트·역할에 따른 서버 측 접근 통제
  • 합성 작성자·승인자·운영자·감사 열람자 역할
  • 보관 잠금과 백업·복구를 포함한 증적 수명주기

화면은 합성 감사 열람자로 검증한 예시입니다. 실제 기관 신원 연동은 별도 적용이 필요합니다.

확인한 기능과
기관에서 결정할 조건을 구분합니다.

첫 도입은 합성 자료와 한정된 저장소에서 시작하세요. 검증 범위를 정한 뒤 실제 기관 적용 여부를 판단할 수 있습니다.

지금 실행할 수 있는 것

탐지·게이트·독립 승인·서명 증적·보관 및 복구·관리 API와 화면·승인된 수정의 격리 검증을 로컬에서 확인할 수 있습니다.

도입 전에 확정할 것

기관별 규정 적용, 운영 신원·키, 보존 분류, 실제 CI 연결, 모델 사용·반출 범위와 파일럿 책임자를 결정해야 합니다.

지원 경계 현재 분석은 제한된 Python AST 범위입니다. 전체 수정 격리 검증은 macOS에서 확인했습니다. 참조 데모의 모델은 fixture이며 실제 LLM 추론·품질을 검증한 결과가 아닙니다.
