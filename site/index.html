도입팀은 탐지 결과뿐 아니라 누가 어떤 정책으로 판단했는지, 어떤 수정과 재검사를 거쳤는지 확인해야 합니다. GovCode Harness는 그 연결을 로컬 참조 코드로 제공합니다.

개발팀의 변경 검사

제한된 Python 구문에서 개인정보 로깅 위험을 검사합니다. 미분석·오류·검토 필요를 통과로 바꾸지 않으며, 수정 후 새 commit을 다시 검사합니다.

정책 담당자의 통제

작성과 승인을 분리하고, 정책 묶음의 서명·범위·만료·철회를 확인합니다. 예외도 대상 commit과 탐지 내용에 결합합니다.

감사 담당자의 추적

원문을 제외한 증적 투영에 서명하고, 실행의 부모 관계를 보존합니다. 이동 후 무결성 확인과 현재 변경의 통과 판정을 구분합니다.

실행·정책·증적을
같은 화면에서 확인하세요.

한국어 관리 화면에서 역할별로 정책과 실행을 살펴보고, 수정·재검사·예외 이력을 따라갈 수 있습니다.

  • 기관·프로젝트·역할에 따른 서버 측 접근 통제
  • 합성 작성자·승인자·운영자·감사 열람자 역할
  • 보관 잠금과 백업·복구를 포함한 증적 수명주기

화면은 합성 감사 열람자로 검증한 예시입니다. 실제 기관 신원 연동은 별도 적용이 필요합니다.

지금 실행할 수 있는 것

탐지·게이트·독립 승인·서명 증적·보관 및 복구·관리 API와 화면·승인된 수정의 격리 검증을 로컬에서 확인할 수 있습니다.

도입 전에 확정할 것

기관별 규정 적용, 운영 신원·키, 보존 분류, 실제 CI 연결, 모델 사용·반출 범위와 파일럿 책임자를 결정해야 합니다.

지원 경계 현재 분석은 제한된 Python AST 범위입니다. 전체 수정 격리 검증은 macOS에서 확인했습니다. 참조 데모의 모델은 fixture이며 실제 LLM 추론·품질을 검증한 결과가 아닙니다.
